{\Large\bfseries Inputs for the neutron--proton converter}

This package contains \field{npc_prebreakout_models.h5}. It has six
pre-breakout jet/ejecta calculations: \field{ana_reference},
\field{ana_neutron_rich}, \field{ana_steeper_tail}, \field{num_dd2_equal},
\field{num_sfho}, and \field{num_sly}. The time coordinate is in the lab
frame. Each model has 201 samples ending shortly before its breakout time.

The HDF5 file is self-describing: every dataset has \field{unit} and
\field{frame} attributes. The file schema is
\field{jetbns.npc-model-export.v3}.

\section*{Reading a model}

Only Python, NumPy, and h5py are needed:

\begin{verbatim}
import h5py

with h5py.File("npc_prebreakout_models.h5", "r") as f:
    g = f["models/ana_reference"]
    time = g["time_s"][:]
    radius = g["radius_cm"][:]
    Gamma_rel = g["relative_lorentz_factor"][:]
    n_p = g["proton_number_density_cm3"][:]
    n_n = g["free_neutron_number_density_cm3"][:]
    B = g["upstream_magnetic_field_g"][:]
    tau_np = g["neutron_to_proton_optical_depth"][:]
    tau_pn = g["proton_to_neutron_optical_depth"][:]

    t_bo = g.attrs["breakout_time_s"]
    r_bo = g.attrs["breakout_radius_cm"]
\end{verbatim}

The last array element is the last pre-breakout sample; it is not the exact
breakout state. The exact breakout time and radius are stored as group
attributes. The group \field{prebreakout_summary} contains the corresponding
endpoint values for all models.

The group \field{jet_cocoon} contains the cocoon radius, energy, pressure,
deposition rate, jet area, and jet opening angle. The group
\field{snapshot_columns} contains frozen radial-column diagnostics.

\section*{Density and optical-depth convention}

The exported free-nucleon estimates are
\[
n_p=Y_e\rho/m_p, \qquad n_n=X_{n,\rm free}\rho/m_p.
\]
The two local encounter depths use the same $pn$ cross section and the
effective upstream path length:
\[
\tau_{n:p}=n_p\sigma_{pn}\ell_u, \qquad
\tau_{p:n}=n_n\sigma_{pn}\ell_u.
\]
The notation is projectile:target. These are local input diagnostics, not
full transport probabilities or spectra. The neutron fraction is a
phenomenological free-neutron estimate; bound nuclei and conversion branching
are left to the transport calculation.

The archive is intended to be used as-is. It contains only this note and the
HDF5 file.
